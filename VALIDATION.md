# Результаты проверки Citrus Gate

Проверено локально 15.10.2026. Среда: Windows, Go 1.27.2, PostgreSQL 18.6 в отдельной временной базе. Реальных клиентских данных и реквизитов оплаты в проекте нет.

| Проверка | Результат |
|---|---|
| Типы TypeScript (`tsc -b`) | Пройдена. |
| Production-сборка Vite | Пройдена. |
| Проверка контрастности исходной системы тем | Пройдена. Новая страница дополнительно осмотрена в браузере; исправлен цвет текста для светлой темы. |
| Локальный запуск панели | Панель запускается, вход работает; новая страница открывается; изменения реферальных дней и цены устройства сохраняются через API. |
| Новые тесты `-run Citrus` | 9 тестов: рефералы/возврат/повторы, устройства/продление/возврат, полномочия и одноразовые подтверждения админ-бота, настройки/CSRF, границы льготного периода, ограничения назначения на ноде, загрузка подписок и JSON-автовыбор. Пройдены. |
| Полный пакет тестов billing | Пройден, 218.779 с. Первый общий прогон прерван общим лимитом времени; отдельный повтор завершился успешно. |
| Полные пакеты subs, nodesync, domain | Пройдены. |
| Тесты резервной копии | 3 теста пройдены: целостность архива, запрет выхода за каталог и запрет подмены Compose даже с пересчитанным манифестом. |
| Синтаксис команды `citrus` | `bash -n` пройден. |
| Сборка Go для Linux amd64 | Панель и нода собираются с `CGO_ENABLED=0`. |
| Проверка Xray | Официальный Xray 26.3.27 принял 4 сгенерированных JSON-профиля, включая группу leastPing и отдельные REALITY, gRPC, XHTTP. Проверка `run -test`, без подключения к серверам. |

## Что не подтверждено

- Полный набор интеграционных тестов ноды не проходит на этой Windows-среде: три исходных теста Unix-сокетов завершаются ошибками Windows IPC. Тест нового ограничения Telegram пройден отдельно. Полный прогон ноды нужен на Linux.
- Docker здесь недоступен, поэтому сборка Docker-образа и фактический запуск Compose на Linux не выполнены.
- Реальный перенос между двумя VPS, DNS-переключение и повторная привязка удалённых нод не проверены. Проверены валидатор архива и синтаксис сценария.
- Не выполнялись настоящие платежи Telegram Stars и платежи через внешних адаптеров. Логика начисления и возврата проверялась с имитацией подтверждений провайдера и настоящей PostgreSQL-транзакцией.
- Не проверялся импорт на физических устройствах во всех версиях Happ/v2RayTun. Принятие конфигурации ядром Xray не доказывает поддержку всех её полей конкретным приложением.
- У внешнего поставщика не создаются отдельные реквизиты на каждого клиента вашей панели; общие сторонние ключи не позволяют обеспечить ваши индивидуальные лимиты или отзыв доступа.

Это исходный проект с реализованными функциями и локальными проверками, а не подтверждение готовности конкретной серверной установки к эксплуатации. Последовательность установки и эксплуатационные ограничения — в `README.md`.
