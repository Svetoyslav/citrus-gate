# Citrus Gate

Неофициальная изменённая версия [Mikan](https://github.com/Miroshka000/mikan) с функциями управления подписками, показанными в задании. Основа: `262ee5ae68fb1713473ba65848b5b66d4e592774`, дата изменений — 15.10.2026. Код Go + PostgreSQL + React, ядро mihomo. Лицензия GPL-3.0 и исходное авторство сохранены в `LICENSE` и `NOTICE.md`. Сборка не является релизом Mikan и не поддерживается его авторами.

## Что добавлено

| Функция | Реализация |
|---|---|
| Рефералы | Личная ссылка в боте и Mini App; бонусные дни за первую оплаченную подписку приглашённого аккаунта; защита от повторного начисления и самоприглашения; отмена бонуса при возврате платежа. |
| Переезд | Команда `bash citrus move root@HOST`: перенос исходников, образа, базы, настроек, сертификатов и ключей; проверка состава и SHA-256 файлов перед восстановлением. |
| Внешние подписки | HTTPS-источники Clash YAML и списки URI, включая Base64; автоматическое обновление; своё название; выбор тарифов; выдача совместимых серверов клиентам. |
| Админ-бот | `/admin`: клиенты, сроки, смена тарифов, отвязка устройств, список нод и включение/отключение удалённых нод. Изменения требуют одноразового подтверждения и записываются в журнал. |
| Докупка устройств | Покупка +1 устройства через Telegram Stars и существующий интерфейс платёжных адаптеров; без изменения срока; повторный платёж не начисляется дважды; покупка сохраняется при продлении. |
| Сутки на продление | 24 часа после окончания срока: один выбранный протокол, только IP-диапазоны Telegram и порт 443; ограничение на самой ноде; выключенные пользователи не восстанавливаются. |
| Автовыбор Xray | JSON-подписка с именованной группой, observatory и leastPing, резервным сервером и отдельными ручными профилями. |

Настройки находятся в разделе **«Возможности Citrus Gate»**. По умолчанию новые функции выключены, цены равны нулю, список Telegram-администраторов пуст.

## Установка на чистый сервер

Нужны Linux (Ubuntu 22.04+/Debian 12+), Docker с Compose v2, Python 3, `tar`, `flock`, свободные порты и доступ к реестрам зависимостей. Рекомендуется от 2 ГБ RAM для сборки. Выполняйте команды от root; скрипт сам Docker не устанавливает.

Скачайте исходники, распакуйте архив или клонируйте этот репозиторий, перейдите в его каталог:

```bash
chmod +x citrus
bash citrus install vpn.example.com 2053
```

Замените домен своим; он должен указывать на сервер. Для установки без домена можно указать публичный IP. В конце выводятся ссылка, логин и одноразово показанный пароль администратора. Не публикуйте их. Сначала проверьте вход, затем создайте пользователя и импортируйте его подписку в клиент.

Скрипт собирает **этот исходный код** в локальный образ `citrus-gate:1.0`; готовый официальный образ Mikan не содержит этих изменений. Внутренние имена бинарников, таблиц и переменных окружения `MIKAN_*` сохранены для совместимости данных.

```bash
bash citrus status
bash citrus logs panel
bash citrus logs node
bash citrus url
bash citrus stop
bash citrus start
```

Установка включает три контейнера: панель, локальная нода и PostgreSQL. База доступна через локальный Unix-сокет и не публикует сетевой порт. Данные панели и ноды разнесены по каталогам. `.env`, `.node.env`, `data/` и `state/` не должны попадать в Git.

## Настройка функций

1. В разделе Telegram задайте токен своего бота и включите его. Бот встроен в эту сборку: отдельный официальный аддон бота не нужен.
2. Настройте тарифы и оплату. Telegram Stars работают через тот же токен бота. Для рублей нужен запущенный совместимый платёжный адаптер; его установка и реквизиты не входят в эту сборку Docker Compose. Цена указывается в копейках.
3. В «Возможностях Citrus Gate» задайте число реферальных дней и цены +1 устройства. Бот показывает кнопки «Пригласить друзей» и «+1 устройство»; команды `/ref` и `/devicesplus` делают то же самое. В Mini App разделы доступны только после проверки Telegram `init_data`.
4. Впишите **числовой Telegram ID** администратора, затем используйте `/admin`. Имя пользователя `@username` не служит доказательством полномочий. `/user ID` открывает конкретного клиента. Смена тарифа сохраняет его текущий срок. Одноразовое подтверждение действует 5 минут, привязано к администратору и не переживает перезапуск.
5. Для суток на продление выберите ID включённого персонального подключения, доступного клиентам. Все ноды должны использовать код этой сборки: старые ноды не понимают новое ограничение. Диапазоны Telegram зафиксированы по [официальному списку](https://core.telegram.org/resources/cidr.txt) на дату разработки. DNS-запросы, сторонние сайты оплаты и Mini App через льготный доступ не разрешены. Продлевать можно в самом боте, например Stars.
6. Для автовыбора включите JSON-подписку Xray и задайте название. Приложение должно поддерживать полную JSON-конфигурацию Xray, observatory и leastPing. Это не универсальное расширение обычного списка URI. Проверяйте конкретную версию Happ/v2RayTun перед массовым включением. Явный `?format=uri` сохраняет обычные ссылки; `?format=xray` отдаёт JSON. Автопрофиль включает конвертируемые VLESS, VMess, Trojan и Shadowsocks; остальные протоколы продолжают работать в обычных поддерживающих их клиентах. Выбор идёт по задержке HTTP-пробы, а не по измерению пропускной способности.

Реферальный бонус выдаётся один раз за Telegram-аккаунт приглашённого, только за первую полную покупку/продление, а не за пробный период, трафик или устройство. Уже существующий подписчик не регистрируется как новый приглашённый. У бессрочного пригласившего срок не меняется. Возврат покупки снимает выданные дни; лимит устройств при возврате уменьшается без удаления самого пользователя.

## Внешние источники

Добавьте HTTPS-ссылку на порту 443, название, интервал 5–10080 минут и при необходимости ID тарифов. Пустой список тарифов разрешает источник всем активным клиентам. Кнопка «Обновить» запускает загрузку сразу; фоновая проверка расписания идёт раз в минуту.

При сбое сохраняется последняя успешная версия, но не дольше 24 часов. Размер ответа ограничен 2 МиБ, число серверов — 2000. Локальные, служебные и частные адреса назначения загрузки блокируются; перенаправления проверяются, DNS-адрес проверяется и закрепляется при соединении. Сообщения об ошибках не содержат секретную ссылку.

**Это агрегатор подписок, а не выдача новых учётных записей у внешнего провайдера.** Подключение клиента идёт непосредственно на его сервер с реквизитами из источника. Устройства и трафик таких подключений ваша панель посчитать и ограничить не может. Условия, квоты, право перепродажи и отзыв ключей определяет внешний поставщик. Удаление источника из панели не отзывает уже выданный сторонний ключ. Учитывайте это при продаже.

## Удалённые ноды

Добавьте ноду в панели, скачайте на её сервер исходники **этой** сборки и выполните показанную команду:

```bash
bash citrus node 'КЛЮЧ_ИЗ_ПАНЕЛИ'
```

Для ноды используйте отдельный каталог без `.env` панели. Команда собирает тот же образ и запускает только ноду; ключ сохраняется в закрытом `.node.env`. Не используйте команду установки оригинального Mikan: она установит другую сборку. Автоматические обновления панели и нод из официальных релизов отключены; обновляйте этот проект пересборкой исходников.

## Резервная копия и перенос

```bash
bash citrus backup /root/citrus-backup.tar.gz
bash citrus move root@203.0.113.20
```

Для переноса нужен заранее настроенный SSH-вход root и Docker/Compose/Python/flock на новом сервере. Каталог `/opt/citrus-gate` на нём должен отсутствовать. Архитектуры процессора серверов должны совпадать. Архив содержит ключи доступа и пароль БД — храните его как секрет; `state/` имеет права 700, архив — 600.

Перед финальной копией исходная панель и локальная нода останавливаются. При ошибке скрипт пытается запустить их обратно. После успешного переноса исходная панель остаётся остановленной, чтобы два экземпляра не опрашивали одного Telegram-бота. Перенос не является бесшовным: будет перерыв на копирование и запуск.

**Ссылки подписок сохраняются при сохранении домена, пути и порта.** После переноса направьте DNS домена на новый IP, откройте нужные порты, обновите публичный адрес локальной ноды и проверьте доступность API удалённых нод, включая ограничения на IP в межсетевом экране. Ссылки с числовым IP невозможно автоматически направить на другой IP. При смене адреса панели повторная привязка удалённых нод может потребовать нового join-ключа.

Ручное восстановление в свежем каталоге исходников:

```bash
bash citrus restore /root/citrus-backup.tar.gz
```

Архив проверяется до распаковки: разрешённые пути, отсутствие ссылок и специальных файлов, SHA-256, доверенный локальный шаблон Compose и локальный адрес базы. Существующие данные не перезаписываются: восстановление требует каталога без `data/` и `.env`. Скрипт относится к установкам Citrus Gate; импорт действующего оригинального Mikan требует отдельного переноса и резервной копии, не запускайте его поверх `/opt/mikan`.

## Проверка и разработка

```bash
cd web
pnpm install --frozen-lockfile
pnpm build
cd ..
MIKAN_TEST_DATABASE_URL='postgres://.../disposable_db?sslmode=disable' go test ./internal/panel/features ./internal/panel/billing ./internal/panel/subs ./internal/panel/citrusbot ./internal/panel/app ./internal/node -run Citrus -count=1
python3 scripts/test_backup_manifest.py
docker build -t citrus-gate:1.0 --build-arg VERSION=citrus-gate-1.0 .
```

Нужны Go 1.27, Node 24, pnpm из `web/package.json`, тестовый PostgreSQL 18. Используйте отдельную тестовую базу. Полный набор проверок исходного проекта рассчитан на Linux и дополнительно требует `pg_dump`/`pg_restore`.

Результаты локальных проверок и ограничения приведены в `VALIDATION.md`. Без настоящего сервера, токена бота, платёжного аккаунта и версий клиентских приложений нельзя подтвердить реальные платежи, перенос между VPS и поведение каждого VPN-клиента. Перед эксплуатацией выполните эти проверки на тестовых пользователях.
